# キット方向性の進捗表

最終更新: 2026-10-22（`feat/github-copilot-migration-kit` の a0a2998、PR #9 マージ後）

## 方向性（2026-10-21 決定）

- スリム化と開発継続に賛成。キットの役割は「モデルの外で正しさを確かめる仕組み」。
- キットが手放すのは LLM の起動制御だけ。固定レビュー入力（`lib/review.mjs`）、JSON 契約検証、
  出力先制限・排他、入力ハッシュによる失効判定（`currentRecord`/`contextHash`）、gate の hook ask は残す。
- 旧ランナーは新方式との比較評価が終わるまで基準として残す。行数は目標にしない。

状態は「完了」「一部」「未着手」「保留（人の手元が必要）」の4つ。
